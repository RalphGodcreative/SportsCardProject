如何使用這個頁面

交易資料（上方）
date / type / amount 為必填；note 可選填，按上方的 + note 展開。
amount 填整筆交易的總金額，不是單張卡的價格。

交易類型
Sell — 賣出
Trade — 換出（拿去交換的卡）
（以上皆為卡片「出售／送出」的紀錄；取得請至 Add Transaction 頁面。）

找卡片（下方）
在 Find cards to sell 填任意欄位，空白的欄位會被忽略，按 search 搜尋。
在結果表格中按 add to sale 把卡片加入這筆交易；同一張卡只能加入一次。
clear — 收起搜尋結果

這筆交易賣掉的卡片（中間）
show / hide — 顯示或收起卡片的簡要資訊
remove — 從這筆交易移除這張卡

至少加入一張卡片後，按 Add Transaction 儲存整筆交易。
